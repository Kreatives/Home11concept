# Home11 concept

Statische conceptwebsite voor Home11, met responsive pagina’s, animaties en een contactwidget.

## Lokaal bekijken

Open `index.html` in een browser, of start vanuit deze map een lokale webserver:

```sh
python3 -m http.server 8080
```

Open daarna `http://localhost:8080`.

## Bestanden

- HTML-pagina’s staan in de hoofdmap.
- Afbeeldingen, video, CSS en JavaScript staan in `assets/`.
- `assets/styles.v4.css` bevat de gedeelde vormgeving.
- `assets/app.v4.js` bevat navigatie, sliders en contactwidget.

Het contactformulier vereist een backend voor het daadwerkelijk versturen van berichten. Lettertypen en enkele scripts worden extern geladen.
